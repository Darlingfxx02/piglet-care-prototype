# Поросята

Интерактивный frontend-прототип приложения доставки поросят по авторскому Figma-макету. React, TypeScript, Vite и обычный CSS. Сервер не требуется.

## Запуск

```sh
npm ci
npm run dev
```

`npm run build` проверяет TypeScript и создаёт статическую сборку в `dist`. `npm run preview` открывает эту сборку локально. `npm run deploy` собирает приложение и публикует `dist` в ветку `gh-pages` текущего репозитория.

## Что работает

* Главная: поиск по номеру и породе, карточки доставок, горизонтальная карусель статистики, уведомления и просмотр животных.
* Поддержка: выбор заказа, сохранение контекста, сообщения пользователя, локальные ответы, быстрые ответы и подтверждение завершения.
* Оценка: пять звёзд, причины низкой оценки, необязательный комментарий, подтверждение и пропуск.
* История и отзыв сохраняются в localStorage. Сброс доступен через «О прототипе».
* Мобильная, планшетная и настольная вёрстка. Маршруты на hash, поэтому прямые ссылки работают на GitHub Pages.

## Архитектура

* `src/app`: маршрутизация и композиция приложения.
* `src/domain`: типизированные демонстрационные данные, reducer диалога, проверка сохранённого состояния.
* `src/features`: главная, заказы, поддержка и оценка.
* `src/shared`: общие элементы и карта оригинальных ресурсов Figma.
* `src/styles.css`: визуальные правила и адаптивные состояния.
* `public/assets`: локальные исходные иллюстрации и SVG из Figma, без внешних временных URL.

Шрифт Onest поставляется локально через Fontsource. Иконки и иллюстрации взяты из макета. Вёрстка не использует изображения целых экранов.

## Границы прототипа

Все заказы, животные и ответы демонстрационные. Чат не связан с оператором. При выборе файла показывается только его имя, файл никуда не загружается. Магазин, покупка, запись к ветеринару и реальные уведомления не подключены. Пароли, авторизация и платежи отсутствуют.

Готовые области перенесены из Figma. Эскизные блоки с условным шрифтом исключены. В чате быстрые ответы закреплены над полем ввода, повторяющийся вариант заменён на «Уточнить время». В мобильной и настольной версиях приведены к общим данным дата ближайшей доставки и номера бирок. Оценка начинается с нуля выбранных звёзд, отправить её без выбора нельзя.

## Проверка

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

Unit-тесты проверяют переходы состояния, контекст заказа, отрицательную оценку, восстановление повреждённого хранилища и поиск. Playwright проверяет полный сценарий, перезагрузку, отсутствие горизонтального переполнения и загрузку изображений на ширинах 320, 390, 768 и 1440 px.

Визуальная сверка выполнена по основным экранам Figma: `151:3264`, `229:4993`, `229:4110`, `229:1050`, `229:5684`, `11:5`, `329:8244`, `329:8367`. Снимки браузера находятся в `tests/screenshots`. Отличия сглаживания шрифта между Figma и браузерами возможны.

Прототип не собирает аналитику и не отправляет содержимое переписки на сервер.
